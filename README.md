# QazTrip AI — Алматы өңіріне арналған ЖИ-туризм платформасы (MVP)

StartUp Battle — IT FEST 2026 байқауына арналған прототип.

**Мақсатты аудитория:** Алматы маңындағы табиғи жерлерге (Шарын, Көлсай, Қайыңды, Үлкен Алматы көлі) өз бетімен баратын шетелдік туристер (18–40 жас). Әдепкі тіл — ағылшын.

## Мүмкіндіктер
- **Кез келген тіл:** қазақша, орысша, ағылшынша интерфейс дайын тұр. Қалған кез келген тілге Gemini аударады, аудармалар серверде және браузерде кэштеледі.
- **ЖИ-жоспарлаушы** (`/planner`): күн бойынша маршрут құрады. Бағаны ЖИ емес, сервер `data/places.json` базасынан есептейді. Базада бағасы жоқ нәрсе «белгісіз» болып көрсетіледі.
- **Орындар каталогы** (`/places`): 18 орын. Барлық бағалар `verified: false` («тексерілмеген») деп белгіленген.
- **ЖИ-чат** (`/chat`): жаңа ақпарат керек болса, Tavily арқылы іздейді және дереккөз сілтемелерін көрсетеді.
- **Жол жағдайы:** әр табиғи орында `roadStatus` бар (`open` / `limited` / `closed`, түсініктеме, `lastChecked`, дереккөз, `verified: false`). Жабық жолдағы орынды ЖИ ұсынбайды, ал сервер оны маршруттан алып тастайды. Шектеулі жол туралы ескерту шығады.
- **Жүргізушілер** (`data/drivers.json`): тек есімі, көлік түрі, орын саны, маршруттары, бір сапар күнінің бағасы, тілдері, `verified`, `consent`, `isDemo`. Телефон нөмірі сақталмайды. ЖИ жүргізушіні тек id арқылы таңдайды, ал бағаны сервер есептейді (бір күнге бүкіл көлік, топқа бөлінеді). Пилотта барлық жазба — «Demo data».
- **Request a driver:** маршрут туралы дайын хабарламамен `https://wa.me/<NEXT_PUBLIC_REQUEST_WHATSAPP>` сілтемесін ашады. Сайт ештеңе сақтамайды, сұранысты QazTrip командасы қолмен өңдейді. Айнымалы бос болса, батырма көрінбейді.
- **Private driver** — «Getting around» тізіміндегі бірінші таңдау. Табиғи орын таңдалып, көлікті турист өзі таңдамаса, ол әдепкі болады. Бұл күндері ЖИ жүргізушіні id арқылы таңдайды, ал қала ішіндегі жолдар жүргізушінің күндік бағасына кіреді. Бюджетке сыймаса да, сервер жүргізушіні өздігінен жалға алынған көлікке ауыстырмайды.
- **USD баламасы:** әр бағаның жанында «≈ $… approx.» тұрады. Курс бір жерде сақталады (`lib/currency.ts`, 1 USD = 500 ₸), негізгі валюта — ₸.
- **Жауапты ЖИ:** ЖИ-дің әр жауабының жанында белгі тұрады. ЖИ-дің жұмысы `/how-ai-works` бетінде түсіндірілген.

## Құрылым
- `app/api/*`: серверлік API (translate, plan, chat, status). Кілттер тек осында қолданылады.
- `lib/gemini.ts`: Gemini клиенті. Әдепкі модель `gemini-3.8-flash`, оны `GEMINI_MODEL` арқылы ауыстыруға болады.
- `lib/tavily.ts`: веб-іздеу.
- `lib/rateLimit.ts`: IP бойынша сұраныс шектеуі.
- `lib/dictionaries.ts`: интерфейс мәтіндері (en/kk/ru).
- `data/places.json`: орындар базасы.
- `data/drivers.json`, `lib/drivers.ts`: жүргізушілер базасы. `lib/request.ts`: WhatsApp хабарламасы.
- `data/costs.json`: жалпы шығындар базасы (метро, автобус, такси, тамақ, хостел, қонақүй, көлік жалдау, жанармай, пәтер, азық-түлік). `unit` өрісі бағаның кімге екенін көрсетеді: `person` — бір адамға, `vehicle` — бір көлікке, `room` — бір бөлмеге. `capacity` — бір көлікке не бөлмеге сиятын адам саны.

## Іске қосу
```bash
npm install
cp .env.example .env.local   # кілттерді .env.local файлына жазыңыз
npm run dev                  # http://localhost:3000
```

## ЖИ сапасын өлшеу
- `lib/planValidation.ts`: ЖИ маршрутын базамен тексереді. Базада бар орындар мен баға сілтемелерінің үлесін, күн санын және ЖИ мәтінге жазып жіберген, сервер алып тастаған сомаларды санайды.
- `npm test`: валидаторға арналған 6 unit-тест (ЖИ шақырылмайды).
- `npm run eval`: іске қосылып тұрған сайтқа (`npm run dev`) 5 тұрақты сценарий жіберіп, метрикаларды `eval-results.json` файлына жазады. Gemini квотасынан шамамен 5 сұраныс жұмсайды.
- «ЖИ туралы» бетінде сервер іске қосылғаннан бергі жиынтық метрикалар көрсетіледі.
- Gemini қатесі (`lib/aiRetry.ts`): 503/500/429 келсе, сол модель 3 әрекетке дейін exponential backoff-пен (1 с, 2 с) қайталанады. Timeout, 404 немесе бұзылған жауап келсе, тізімдегі келесі модельге ауысады. Резервтік модельдер `GEMINI_FALLBACK_MODEL` айнымалысында үтір арқылы жазылады. Барлық модель істемесе, пайдаланушыға «ЖИ қазір бос емес, бірнеше секундтан соң қайталаңыз» хабары мен «Қайталау» батырмасы көрсетіледі. Әр шақырудың уақыт шегі бар, сондықтан сұраныс Vercel-дің 60 секундтық шегіне сыяды.
- Аударма істемесе, интерфейс ағылшынша қалады, ал жоғарғы жолақта «Қайталау» батырмасы шығады.
- Туристің жағдайы (`lib/conditions.ts`): формадағы түнеу, көлік және тамақ таңдауы, оған қоса еркін мәтін. ЖИ мәтінді құрылымды шарттарға айналдырады (мәтін басым, белгілі бір күнге ғана қатысты ерекшеліктер бөлек жазылады). Мәтін бос болса, форма қолданылады. Түнеу, көлік жалдау, жанармай және азық-түлік шығынын сервер шарттарға қарап өзі қосады, ал тегін жағдайларда 0 ₸ мен түсініктеме көрсетіледі. Пайдаланушы шарттарды түзетсе, маршрут `/api/plan/recalc` арқылы ЖИ-сіз қайта есептеледі.
- Нақты тілектер (`lib/wishes.ts`): формада пайдаланушының өзі өзгерткен өрістер, мәтіннен анықталған тілектер, белгілі бір күнге қатысты ерекшеліктер және сұралған орындар ешқашан бюджет үшін ауыстырылмайды. Бюджеттен асса, сервер әр тілектің құнын («X ₸ асады, арзанырақ нұсқа: …, Y ₸ үнемдейсіз») есептеп көрсетеді. Пайдаланушы көрсетпеген нәрселерді сервер ең арзан нұсқаға ауыстырады және мұны ашық айтады. ЖИ-дің қайта жоспарлауы сұралған орынды алып тастаса, қабылданбайды.
- Бюджет (`app/api/plan/route.ts`, `lib/budgetAdvice.ts`): белгілі шығын бюджеттен асса, сервер ЖИ-ге бір рет кері байланыс жібереді, ЖИ маршрутты бір рет арзанырақ нұсқалармен қайта құрады. Жаңа жоспар арзанырақ болса ғана қабылданады. Сонда да сыймаса, сервер ең аз бюджетті және үнемдеудің 2–3 жолын базадан есептейді.
- `npm test` retry логикасын да жасанды ЖИ қателерімен тексереді (9 тест).

## Бағаларды тексеру
`data/places.json` және `data/costs.json` файлдарында әр бағаны тексеріп болған соң `"verified": false` мәнін `true` деп өзгертіңіз. Сонда «тексерілмеген» белгісі жоғалады.
